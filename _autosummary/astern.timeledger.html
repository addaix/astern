astern.timeledger

astern.timeledger¶

Time ledger: where the owner’s time and the agents’ time went, per bucket, over a window.

Three steps, each usable alone:

  • activity() reads transcripts (any homes, so several machines) and returns, per top-level session, the agent’s active seconds as runs of [cwd, day, seconds], and every owner prompt (time, cwd, length). Active time is the sum of gaps between consecutive events, each gap counted only up to idle seconds. An owner prompt is a user line the transcript marks origin.kind == "human" (typed by a person, locally or by remote control), minus briefs another agent sent that way (dispatch_markers). Events are deduplicated by (sessionId, uuid) across files: a session whose repository moved leaves a second transcript copy holding the same events.

  • commits() reads git log of the repositories under a root and classes each commit bot, others (not the owner’s identity: collaborators in shared repos), agent (a Claude trailer or session link in the message), else unmarked (agents commit under the owner’s identity too, so unmarked is not proof of a hand commit). Dated by author date. git log --all overstates distinct changes: a branch commit later repeated by a squash merge counts twice.

  • rollup() groups both by an injected bucket(cwd) -> str | None (see prefix_bucket()). None means “outside every bucket”: that time counts for the

    session’s previous bucket (a scratchpad in /tmp belongs to the project that used it).

    Owner time is credited per prompt as min(W, minutes since the previous owner prompt on any machine), so parallel sessions never double-count one person; W is reported for each of windows (5 minutes, with 2 and 10 as the sensitivity range).

Agent hours are session-hours, not wall-clock: parallel sessions add up. Nothing here reads prompt text beyond its length and the dispatch markers, and nothing is written anywhere.

>>> bucket = prefix_bucket([("t/astern", "astern"), ("t/", "tools")], root="/p")
>>> bucket("/p/t/astern/docs"), bucket("/p/t/ir"), bucket("/p/misc/x"), bucket("/tmp/s")
('astern', 'tools', 'unmapped', None)

astern.timeledger.activity(home=None, *, since, until=None, idle=300, dispatch_markers=('Reply in at most five lines',), files=None)[source]¶

Agent active time and owner prompts from the transcripts of home (see astern.sources.homes(); "all" covers every account and mirrored machine).

since / until are ISO dates or times (UTC; until exclusive). files overrides the transcripts read (tests pass fixtures). Returns {"since", "until", "sessions", "prompts"}: a session is {"session", "home", "active": [[cwd, day, seconds], ...]} with consecutive events in the same cwd and day merged into one run, in order; a prompt is {"ts", "cwd", "chars", "session", "dispatched"}.

Return type:

dict

astern.timeledger.commits(root, *, since, until=None, owner, exclude=('forks/', ), depth=3, timeout=60, run=<function run>)[source]¶

Commits by author date in [since, until) across the repositories under root.

owner is a regex (or a pattern) matched against the author’s email and name. Repositories whose path relative to root starts with one of exclude are skipped. Each commit is {"hash", "date", "repo", "path", "kind"}, once per hash.

astern.timeledger.prefix_bucket(rules, *, root, root_bucket='unmapped')[source]¶

A bucket map from (prefix, bucket) rules, prefixes relative to root; first match wins.

A cwd outside root (or none) maps to None; root itself to root_bucket; a cwd inside it that no rule matches to UNMAPPED. Put longer prefixes first. A rule matches whole path parts: t/ast does not match t/astern.

>>> b = prefix_bucket([["a/b", "B"]], root="/r", root_bucket="lookout")
>>> b("/r"), b("/r/a/b/c"), b("/r/a/bc"), b(None)
('lookout', 'B', 'unmapped', None)
Return type:

Callable[[str | None], str | None]
